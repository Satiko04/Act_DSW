# lab-empresta


To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

This project was created using `bun init` in bun v1.3.13. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.

# Sistema de Empréstimo de Equipamentos do Laboratório

Projeto de Backend com Bun e Express + Frontend HTML/JS Vanilla com fetch nativo.
Implementação de todos os requisitos obrigatórios e recursos de bônus solicitados.
